# Public Repository Boundaries

This repository is the public, static specification surface for REHT.

## Included

- public terminology
- versioned contracts
- reference JSON Schemas
- non-production examples
- architecture descriptions required to understand the public standard
- conformance language
- public change history

## Excluded

- production implementation source code
- proprietary evaluation and authorization logic
- private observation or analysis implementations
- private enforcement-runtime implementation
- internal thresholds, weights and risk models
- customer integrations and customer data
- credentials, infrastructure and deployment configuration
- operational runbooks
- private repository relationships, build sequencing and internal component topology
- unpublished research and patent material

The exclusions are stated as implementation classes rather than a catalogue of private component names. A public boundary document must not itself become a map of the protected system.

## Separation rule

No file may be copied from a private production repository without an explicit public-release review covering intellectual property, security, customer confidentiality, derivation risk and dependency licensing.

Schema compatibility does not imply implementation equivalence, certification, endorsement or compliance.
