# PEACE protocol pointer

PEACE is a separate protocol effort and is not normative REHT material.

The canonical public PEACE interoperability surface lives in the dedicated `nsolland/peace-protocol` repository.

This REHT standards repository intentionally does not duplicate PEACE protocol internals, research derivations, roadmaps, schemas or conformance artifacts. REHT references PEACE only where an explicit interoperability relationship is relevant to REHT semantics.
