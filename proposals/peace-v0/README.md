# PEACE Protocol v0 — public proposal seed

**Personal Execution, Authority & Compute Environment**  
**Your Sovereign State.**

> Status: public proposal / incubation artifact. This directory is intentionally **not** normative REHT material. PEACE is broader than REHT and is expected to graduate to its own vendor-neutral repository/standard surface.

## Why this exists here

PEACE emerged from taking the principle **govern the workspace, not the worker** to its logical conclusion.

If workers are replaceable, then models, agents, devices, compute, services, credentials and providers must also be replaceable. What must persist is the governed domain: identity, authoritative state, standing, authority, delegation, governance, evidence lineage and recovery.

This public seed establishes the protocol thesis, world contract, minimum invariants and machine-readable conformance surface while a dedicated PEACE repository is prepared.

## Relationship to existing open work

PEACE does not replace REHT or Open Agent Contract.

- **Open Agent Contract** describes portable governed intent/contract semantics before execution.
- **REHT** governs whether an exact consequence remains admissible at the execution boundary under current authority and state.
- **PEACE** is the broader sovereign-domain protocol that keeps the principal, authoritative state and authority anchored while capabilities, intelligence, compute, services and economic rails remain replaceable.

Conceptually:

```text
PEACE sovereign domain
  -> governed contract / intent
  -> external capability / intelligence / compute
  -> candidate consequence
  -> REHT fresh execution authorization
  -> effect / settlement
  -> receipt / evidence
  -> admitted state transition
```

## Core thesis

> **Everything can be routed except sovereignty.**

PEACE is intended to be free to adopt, independently implementable and vendor neutral. No provider — including VALO — should need to become the permanent intermediary or authority root.
